# Food Delivery React Web App

A modern and responsive food delivery web application built using React.js. The application allows users to browse food items, add products to the cart, manage quantities, and view order summaries.

## Features
- Food menu browsing
- Add to Cart functionality
- Quantity management
- User authentication
- Responsive design
- Dynamic pricing

## Technologies Used
- React.js
- JavaScript
- HTML5
- CSS3
- Vite
